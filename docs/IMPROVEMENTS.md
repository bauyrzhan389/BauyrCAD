# Improvement log

Friction noticed while doing real work in BauyrCAD: things that were missing, slow, awkward, or
needed a workaround. Claude adds an entry during every project (newest first). Bauyrzhan picks
what gets built next; built items move to `CHANGELOG.md` and are marked done here.

Size: **S** under an hour, **M** a session, **L** several sessions.
Status: `idea` · `planned` · `in progress` · `done (version)` · `dropped`.
