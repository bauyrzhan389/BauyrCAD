# Native SolidWorks export coverage

The standard GUI export requires native history and complete mates. Unsupported
steps and validation warnings stop export instead of silently flattening history.
The scripting API retains its legacy fallback unless `require_native=True`.

This is an implementation matrix, not a claim that every mode of a listed tool
has been verified. Real SolidWorks tests live in `tests/test_solidworks.py` (shared helpers
and one SolidWorks session for the run: `tests/sw_support.py`; per-family files
`tests/test_sw_<family>.py`).

**Verification standard.** Every real-SolidWorks test reopens the saved file and also
decodes it offline with `bauyrcad/core/sldprt.py` (no SolidWorks): the decoded
FeatureManager tree must hold each BauyrCAD step, in order, with the expected
`GetTypeName2`, and equal the tree the SolidWorks API reports (names, ids, types,
suppression); assemblies compare decoded mates with `IMate2` (type, alignment,
suppression, values, components). `sldprt.tree_mismatches` flags any body without
history (`BaseBody`), so a silent solid-body fallback cannot pass as native. The expected
steps come from the BauyrCAD document (`sw_support.doc_steps`), never from the exporter's
own `report.features`, and every absorbed sketch the file declares must be identified
(`SwFeature.unlinked == 0`: loft profiles, sweep paths, sketches of suppressed features).

**Feature types without a native translator yet** (the strict gate refuses them before SolidWorks starts; `solidworks.unsupported_types()`, kept equal to this line by `tests/test_solidworks_export_policy.py`): `boundary`, `intersect`, `rib`, `wrap`.

| Feature family | Current support / evidence | Remaining scope |
|---|---|---|
| Imported base | First solid import becomes Imported (decoded `BaseBody`, the only body without history); STEP, IGES, BREP fixtures exercise subsequent boss/cut (decoded `ICE`) and suppress the cut after reopen (suppression decoded from the saved copy) | Later imports, multi-base imports; no recovery of missing source history |
| Sketch, extrude, revolve | Native sketches and operations, decoded and matched to the API: plate, shaft (Revolve 360 deg + Cut-Revolve 270 deg), block (mid-plane + through-all both), contours, wedge (inclined face), curvy (spline); fully defined sketch (5 driving dimensions decoded). Extrude and revolve go through the same volume + first-moment validation as every handler, with the direction derived (attempt 0, `report.attempts`) and read back (`IExtrudeFeatureData2` / `IRevolveFeatureData2`: end condition, depth, angle, Reverse Direction): base boss reversed, base revolve 90 deg both senses, cut-revolve 90 deg reversed on an axisymmetric shaft, a sketch plane whose normal opposes SolidWorks' sketch normal with an auto-flipped and a reversed cut; a forced wrong-direction attempt is rejected by the first moment (`tests/test_sw_infrastructure.py`) | Model-edge/reference-axis revolve (refused by the pre-check); relations and dimensions: see the next rows. A revolve about an axis line in another sketch, or about an ordinary (non-construction) line outside the profile, makes no feature in SolidWorks: the strict pre-check refuses both before SolidWorks starts (`test_precheck_finds_runtime_only_failures_before_solidworks`; non-strict: one `BaseBody`, decoded). A profile edge used as the axis exports |
| Sketch planes and entities | `tests/test_sw_sketches.py`, every export strict, reopened, decoded, sketch read back (segments by kind and construction, points, Point entities, relation kinds, dimensions, constrained status, `IFeature.GetParents`). **Planes** by `plane_spec`, never a coplanar stand-in or an extra plane: a face whose projected origin lies outside it (offset plate, offset wedge's inclined face), a face lying on the Front Plane or on an earlier `Plane1` (parent = the extrude), a sketch on `Plane2` coincident with `Plane1` (parent `Plane2`), a mid plane; `part.sketch('front')` with a face-driven `Plane1` lying on the Front Plane (parent Front Plane, also for an explicit `SketchPlane` there); explicit planes: a standard plane or an earlier helper plane in the same place (never a transferred reference plane), else a hidden helper `<sketch> Plane` (offset of a standard plane, or normal to a hidden 3D-sketch line); a face reference that no longer resolves is refused by the pre-check (non-strict: helper plane + warning). **Frames**: SolidWorks' sketch axes turned (Modify Sketch) onto BauyrCAD's when Horizontal / Vertical, h/v dimensions or text need it (explicit plane 30 deg off, a face nearly along X: fully defined, 2 H + 2 V, dimensions 3/4/6/8 read back), the origin moved onto BauyrCAD's, and references to the origin of an explicit plane go to a hidden helper point `<sketch> Points` (D1). **Entities**: arcs (centre ccw/cw, 3-point, tangent, fillet, slot) on Front, a -Z back face and a mirrored plane; splines through BauyrCAD's points (3 points natural, 4 exact, 6 uneven: SolidWorks differs by ~0.006 mm³ along the spline whatever the feature's width, a note; narrow 1 mm / 0.3 mm strips under it, also 300 mm from the origin, export strictly: BauyrCAD's volume measured exactly on spline faces + an allowance of 1 µm x free-form face area), `GetPointCount` = BauyrCAD's, a coincident on an interior spline point, a construction spline; Point entities (Fix, midpoint line, centre rectangle / centre slot centres; on a circle centre and on line ends, as the GUI's snapped Point tool makes them: a separate SolidWorks user point at the same place + one checked Coincident); construction circle / arc; shared centres merged (centre slot: 7 points, slot + offset: 10). **Tool results**: centre / 3-point rectangle, parallelogram, polygon (5 equal), straight / centre slot (4 tangent, equal, midpoint), sketch fillet (2 tangent + R4 read back), chamfer, offset (2 parallel), mirror (3 symmetric), trim / extend (collinear), convert entities (fixed curves, as BauyrCAD stores them). **Text** (D7): editable Sketch Text, text / font / bold / italic / height read back, angled and mirrored-frame text along a construction line, letters' volume within 10 % (seen 0.8-5.7 %, a note) and their centroid within 10 % of the text height (seen <= 0.25 mm). Empty and unused (open) sketches kept with their names. A per-sketch parity check (segments by type and construction, sketch points, Point entities) runs before each sketch is closed | Refused before SolidWorks starts: text in a sketch with other (non-construction) curves (SolidWorks did not extrude such a sketch through the API), multi-line text, '<' in text. Convert Entities as 'On Edge' relations would need BauyrCAD to store the source edge. Sketches on the other reference-plane modes (angle, 3-point...) wait for those planes (refused by the pre-check) |
| Sketch relations and dimensions | `tests/test_sw_sketch_relations.py`, every export strict, reopened, decoded, each sketch's relations compared with BauyrCAD's as a multiset of `swConstraintType_e` (`ISketchRelationManager.GetRelations`), its points where BauyrCAD's are after SolidWorks solved it (`assert_sketch_points`), constrained status equal to BauyrCAD's. **Relations** (all 12 types, each call checked: the sketch must gain the expected relation type): coincident point-point (on the origin) and point on a line / arc / circle / spline, midpoint (of a line, a Point entity), Horizontal / Vertical on lines and between points (3 points split into pairs, a point and the origin), parallel / perpendicular, parallel / collinear / equal on 3 lines, equal circles and arc-circle, concentric, tangent (line side, a line end on a circle, external and internal arcs), Fix on a point / line / arc / circle / spline / Point entity, symmetric about a centerline and about an ordinary line (through `ISketchRelationManager.AddRelation`, Add Relations refuses it). A relation SolidWorks refuses is a named blocking warning (`test_refused_relations_are_blocking`). **Dimensions** (every one read back: `IDisplayDimension.Type2`, value, `IDimension.DrivenState`, text position = `c.label`): line length, aligned point-point (with and without a text position), centre-centre and origin-centre (arc end condition centre), point-line, centre-line and parallel line-line (offset tool), circle radius / diameter, arc radius / diameter, angles 35 / 110 deg (API) and 108.4 / 101.3 deg (GUI quadrants), horizontal / vertical; driven dimensions (a redundant diagonal, a free diameter) as driven SolidWorks dimensions in a fully defined sketch; a driving dimension SolidWorks finds over-defining is a blocking warning (`test_over_defining_dimension_is_blocking`) | Equal between a line and an arc/circle (no SolidWorks equivalent: refused in BauyrCAD and by the pre-check), relations to a point no entity uses, angles between parallel lines, relations that do not hold (refused by the pre-check). Dimensions bound to parameters / equations wait for the equations package |
| Fillet, chamfer, shell, draft, hole | Native applied-feature fixtures | Every selection/mode combination |
| Linear/circular patterns, mirror | Native feature patterns and mirror fixtures | Body patterns and remaining modes |
| Reference geometry: planes, axes, points, curves | `tests/test_sw_reference_geometry.py`, every export strict, reopened, rebuilt, decoded; each reference feature read back from the saved file (definition and geometry against BauyrCAD's) and used by a later feature by its BauyrCAD feature id. **Reference planes** (`RefPlane`, `IRefPlaneFeatureData` type / constraints / distance / angle / references, `IRefPlane.Transform` origin and normal): offset from a standard plane +15 / -15 (Flip offset, 8\|256), from a model face, from an earlier plane (reference = `Plane3`), 0 = Coincident (4), Mid Plane between two faces and between Front and an earlier plane (128, 128), with an explicit second plane (hidden helper `<plane> Plane`); At angle (16 [+256], 4) about the Y axis (helper axis), a model edge with a negative angle, a reference axis at 240 deg; three points (4, 4, 4) on model vertices, and in mid-air (helper `<plane> Points`) with Flip (the points' order reverses the normal); normal to a curve (2, 4) through a point: global X + point (helpers), a model edge with no point (its start vertex), a reference axis + a vertex; a sketch's own plane (`part.plane(sketch, ...)` references the sketch's standard / reference plane, no helper) and an explicit tilted plane (helper). Sketches on each plane sit on it (`GetParents`), their points where BauyrCAD's are; holes / bosses on the axis-aligned planes prove the place by volume and centre of mass. **Reference axes** (`RefAxis`, `IRefAxisFeatureData.Type`, `GetRefAxisParams` on BauyrCAD's line): cylinder face (3), planar face normal through its centre (Point and Face 4 + helper Center-of-Face point `<axis> Points`), straight edge (0), circular edge (the coaxial cylinder, 3; else Point and Face with an Arc Center helper), two planes (1), two points on vertices / in mid-air (2, helper points), point + direction (two helper points; along X / Y / Z: the two standard planes, no helper); a circular pattern about `Axis1` and a linear pattern along `Axis5` select them. **Reference points** (`RefPoint`, `IRefPointFeatureData.Type`, `GetRefPoint`): coordinates ('On Point' 7 of a hidden 3D-sketch point `<point> Points`), Arc Center (3), Center of Face (4) on a planar and on a cylindrical face; a three-point plane and a two-point axis select the native points (no helpers). **Curves**: Curve Through XYZ Points (`CurveInFile`, `IFreePointCurveFeatureData.PointArray` = BauyrCAD's points exactly) open and closed (first point repeated), BauyrCAD's curve sampled lies on SolidWorks' (both are the chord-length cubic spline with natural / periodic ends, D2) and a sweep along each matches; polylines open and closed as a 3D sketch of joined lines (`3DProfileFeature`, segment and point counts); two points (a straight Curve Through XYZ Points) + sweep | SolidWorks has no Flip Normal for an offset or 'normal to' plane through the API: the plane in the right place is kept with a report note (sketches on it are mapped). Refused before SolidWorks starts: an 'At angle' plane whose axis is not parallel to its base plane, a planar face's normal as the rotation axis, an axis on a non-circular curved edge, a non-axis feature as the axis. BauyrCAD stores 'points' modes as coordinates, so SolidWorks finds vertices / reference points by position (no associativity either side) |
| Helix, sweep, loft | Native fixture coverage. The loft (+ offset plane + sweep) and the spring (helix + sweep) export with `require_native=True`; their small surface differences are report notes, not blocking (`test_blends_export_strictly_with_notes`), also 1 m from the origin (`test_blends_far_from_the_origin_export_strictly`). Helices are checked by their curve (every BauyrCAD point on SolidWorks' helix, same end points), in the handler and on the saved file: explicit axes -y, y (left hand, start 30 deg), x, -z, (1,1,0) away from the origin, and a reversed helix on a sketch on a -Y face (`test_helices_run_where_bauyrcad_has_them`, `test_bodyless_part_exports_natively`); sweeps along Curve Through XYZ Points: see reference geometry | Tube sweeps, ruled/point lofts and remaining modes |
| Rib, wrap, intersect, boundary | Not complete | Native translators and reopen fixtures |
| Suppressed features, equations | Not complete: the strict pre-check refuses suppressed features and any parameter / equation link (so they never arrive silently as plain values). The offline decoder already reads suppression per configuration for every feature kind exported so far (extrudes, Hole Wizard through the 3DExperience store, planes, sketches, fillets: `tests/test_sldprt.py::test_real_suppression_per_configuration`) | Preserve states and parameter relationships; equations are not decoded offline yet |
| Assembly mates | All seven type mappings exist; hinge fixture verifies native mates and remaining motion; its five mates (concentric x2, coincident, distance 5 mm, angle 30 deg) are decoded from the saved file and match `IMate2` type, alignment and suppression | Every type/value/alignment, names and suppression states |

## Exporter infrastructure (every family)

| Piece | Behaviour / evidence |
|---|---|
| Report | `warnings` = real losses (block `require_native`); `notes` = approximations within tolerance (spline and font-outline shapes, joined touching points, blend surface: never blocking); `helpers` = hidden helper geometry; `steps` = a step that became several SolidWorks features (`<name>`, `<name>-2`...); `attempts` = handler attempt kept. Unit: `tests/test_solidworks_export_policy.py::test_notes_do_not_block_strict_export_but_losses_do`; real: `test_blends_export_strictly_with_notes`, `test_multi_feature_step_and_solidworks_own_names` (a 2-point Hole Wizard hole = `Hole1`, `Hole1-2`) |
| Strict pre-check | `native_export_issues` / `assembly_native_issues` without SolidWorks: unsupported types (line above), per-type mode checks (`solidworks_features.PRECHECKS`, the same predicates the handlers run), suppressed features, features in an error state, parameters / equations, later and multi-solid imports, sketch text sharing a sketch with curves / multi-line / '<', sketches whose face reference is lost, sketch relations SolidWorks can't hold (an Equal between a line and an arc, a relation to a point no entity uses, an angle between parallel lines, a relation that does not hold), revolve about a model / global axis, revolve about a line in another sketch or an ordinary line outside the profile. Called by the GUI part and assembly exports before the worker starts and by the strict one-call exports before SolidWorks starts (unit tests in `test_solidworks_export_policy.py`) |
| Validation | Every step: change of volume AND of first moment against BauyrCAD, tolerance relative to the step's own volume change (exact 1e-5, splines 1e-4, sweeps 1e-3, lofts/boundaries 1e-2, sketch text 0.1 plus the letters' centroid within 0.1 x the text height) plus a measurement floor of 1e-8 of the body (SolidWorks measured at its Higher mass-property accuracy) and any difference an earlier step already left, plus OpenCASCADE's own integration uncertainty measured on the two bodies (fixed Gauss vs adaptive: 0 on analytic faces, ~1e-6 of the body on B-spline faces); the first moment is taken about the step's neighbourhood (bounding-box centre), so moving the part does not change the check. A wrong-direction pattern of a 3 mm boss and a swapped 1 x 3 chamfer on a 200 x 200 x 25 mm plate are rejected (`test_small_steps_on_a_large_body_are_placed_exactly`); the saved part: forced rebuild with What's Wrong and `GetErrorCode2` (errors and warnings block, `test_rebuild_health_finds_feature_errors`), final volume and centre of mass |
| Helper geometry (D1) | Hidden, named `<step> Plane` / `<step> Axis` (+ `<step> Axis Sketch` 3D-sketch line) / `<step> Points` (3D-sketch points, or a Center-of-Face / Arc Center reference point), only where no model vertex, earlier reference point or the origin stands at that place, made once and reused, never clearing an in-progress multi-selection (`keep_selection`): `test_helper_geometry_is_named_hidden_and_reported` (offset and inclined explicit sketch planes, an arbitrary pattern direction, two standard axes; BauyrCAD's `Plane1` keeps its name), `test_helpers_keep_an_in_progress_selection` |
| Names | Names are read back; a feature SolidWorks named itself that holds a step's name is renamed out of the way; Hole Wizard's own sketches are named after their hole; a refused name is a blocking warning |
| Document copy | The export works on a private copy regenerated once (cached body before / after each step, O(n)); the edited Document is never touched and a COM error closes the half-built SolidWorks document (`test_export_works_on_a_private_copy_regenerated_once`, `test_a_com_error_closes_the_document_and_leaves_the_part_alone`) |
| Parts without a solid | Sketches, planes and helices only: exported natively, checked to stay body-less (`test_bodyless_part_exports_natively`); the GUI allows it |
| Units and preferences | New parts and assemblies get MMGS (mm, g, s; degrees, 2 decimals), read back on every saved fixture (`check_saved_part`); the toggles the export changes (input dimension value, sketch inference, automatic relations, update component names) are restored, also when an export session nests in a running one (`test_new_documents_are_mmgs_and_preferences_are_restored`) |

Native file extensions alone are not evidence of editability. Verification should
reopen files, check feature types and geometry, and exercise edits or suppression.
An imported base is the recorded starting geometry, not reconstructed design intent.
